# Hand Mouse — мышка, которой управляешь рукой

Скрипт видит руку через веб-камеру и двигает курсор.

## Установка

Нужен Python 3.9–3.12.

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python hand_mouse.py
```

## Жесты

| Жест | Действие |
|---|---|
| Указательный палец | двигает курсор |
| Коротко свести большой и указательный | левый клик |
| Держать их сведёнными | зажать кнопку (перетаскивание) |
| Свести большой и средний | правый клик |
| Поднять указательный и средний (V) и вести вверх/вниз | прокрутка |
| Q или ESC | выход |

Держи руку внутри фиолетовой рамки — рамка соответствует всему экрану.
Если что-то пошло не так, резко уведи курсор в левый верхний угол — скрипт остановится.

## Настройки

В начале `hand_mouse.py`: `SMOOTHING` (плавность), `PINCH_THRESHOLD` (чувствительность щипка),
`FRAME_MARGIN` (размер рамки), `CAMERA_INDEX` (если камер несколько).

## Частые проблемы

- **macOS:** разреши терминалу доступ к камере и к «Универсальному доступу»
  (Настройки → Конфиденциальность и безопасность), иначе курсор не будет двигаться.
- **Linux:** нужна сессия X11 (на Wayland pyautogui не управляет мышью).
- **`module 'mediapipe' has no attribute 'solutions'`:** поставь версию из requirements:
  `pip install mediapipe==0.10.14`.

# Hand Mouse — мышка, которой управляешь рукой

Скрипт видит руку через веб-камеру и двигает курсор.

## Установка

Работает с новыми версиями Python (включая 3.13 и 3.14). При первом запуске скрипт сам скачает модель руки (~8 МБ).

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python hand_mouse.py
```

## Жесты

### Правая рука — мышка
Если в кадре одна рука, мышкой будет она.

| Жест | Действие |
|---|---|
| Указательный палец | двигает курсор |
| Коротко свести большой и указательный | левый клик |
| Держать их сведёнными | зажать кнопку (перетаскивание) |
| Свести большой и средний | правый клик |
| Поднять указательный и средний (V) и вести вверх/вниз | прокрутка |

### Левая рука — команды
Жест надо подержать ~0.7 сек (под рукой появится полоска).

| Жест | Действие |
|---|---|
| 1 палец (указательный) | громкость + (пока держишь) |
| 2 пальца (V) | громкость − (пока держишь) |
| 3 пальца | переключить окно (Alt+Tab) |
| «Коза» 🤘 (указательный + мизинец) | все окна (Win+Tab) |
| Кулак | пауза / воспроизведение |

### Две руки
| Жест | Действие |
|---|---|
| Хлопок | свернуть все окна (ещё хлопок — вернуть) |

**Q** или **ESC** — выход.

Держи руку-мышку внутри фиолетовой рамки — рамка соответствует всему экрану.
Если что-то пошло не так, резко уведи курсор в левый верхний угол — скрипт остановится.

## Настройки

В начале `hand_mouse.py`: `MIN_CUTOFF` и `BETA` (фильтр дрожи), `PINCH_ON` / `PINCH_OFF` (чувствительность щипка),
`FRAME_MARGIN` (размер рамки), `CAMERA_INDEX` (если камер несколько), `MOUSE_HAND` (поменять руки местами, например для левши),
`GESTURE_HOLD` (сколько держать жест), `CLAP_CLOSE` / `CLAP_FAR` (чувствительность хлопка).

## Частые проблемы

- **macOS:** разреши терминалу доступ к камере и к «Универсальному доступу»
  (Настройки → Конфиденциальность и безопасность), иначе курсор не будет двигаться.
- **Linux:** нужна сессия X11 (на Wayland pyautogui не управляет мышью).
- **Курсор дрожит:** уменьши `MIN_CUTOFF` (например, 0.3).
- **Курсор отстаёт при быстрых движениях:** увеличь `BETA` (например, 0.015).

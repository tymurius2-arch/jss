# Угадай цену

Браузерная игра: показывается товар с маркетплейса (Rozetka, Comfy, Allo, AliExpress), игрок называет цену и соревнуется с ИИ-соперником.

- `index.html` — вся игра (без сборки, открывается прямо из файла).
- `products.js` — список товаров (~2800): магазин, категория, название, цена, картинка, ссылка.
  Цены AliExpress хранятся в долларах (`usd`) и переводятся в гривны по `USD_RATE`.
  Товары Rozetka, Comfy и Allo записаны компактными строками в конце файла.

В меню «Настройки» выбираются диапазон цен (0–150 000 ₴), магазины, число раундов и звук; выбор хранится в браузере.
Если картинка товара не загрузилась (ошибка, пустая заглушка или дольше 10 секунд), товар больше не показывается.

Чтобы добавить товар, допишите строку в `products.js`.

Публикуется вместе со школьным порталом на GitHub Pages по адресу `/price-guess/`.

# Угадай цену

Браузерная игра: показывается товар с маркетплейса (Rozetka, AliExpress), игрок называет цену и соревнуется с ИИ-соперником.

- `index.html` — вся игра (без сборки, открывается прямо из файла).
- `products.js` — список товаров: магазин, категория, название, цена, картинка, ссылка.
  Цены AliExpress хранятся в долларах (`usd`) и переводятся в гривны по `USD_RATE`.

Чтобы добавить товар, допишите строку в `products.js`. Если картинка товара не загрузится, игра молча заменит его другим.

Публикуется вместе со школьным порталом на GitHub Pages по адресу `/price-guess/`.

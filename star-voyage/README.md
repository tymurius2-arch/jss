# Звёздный рейс

3D-игра: сам запускаешь ракету с Земли и летишь по всей Солнечной системе. Ракета сделана по мотивам SLS и корабля «Орион» (без логотипов, это фан-игра).

`index.html` — вся игра в одном файле. 3D на [three.js r128](https://threejs.org/) (подключается с cdnjs), поверхности планет рисуются шейдерами из шума, ни одной картинки не скачивается. Звук синтезируется через Web Audio.

## Запуск с Земли

1. «На старт» — ракета стоит на стартовом столе на мысе у океана, рядом башня обслуживания и здание сборки.
2. «ЗАПУСК» — обратный отсчёт 5…0, на T−3 загораются двигатели центрального блока, на нуле — ускорители.
3. Держи «ГАЗ» (или `Пробел`). Следи за шкалой «Нагрузка»: в плотной атмосфере на большой скорости ракету может разорвать. Загорелось «ПЕРЕГРУЗКА» — отпусти газ.
4. Ступени отделяются сами: ускорители, потом центральный блок и башня аварийного спасения. Раскрываются солнечные панели.
5. Выше 500 км — космос, дальше управляешь кораблём сам.

Если взлёт не получился, можно сразу перейти в космос.

## Полёт

| Действие | Клавиатура | Телефон |
|---|---|---|
| Руль | стрелки, или тянуть мышью | тянуть пальцем по экрану |
| Сдвиг влево / вправо | `A` / `D` | — |
| Наклон (крен) | `Q` / `E` | — |
| Газ / тормоз | `W` / `S` | ГАЗ / ТОРМОЗ |
| Турбо (быстрее света) | `Shift` | ТУРБО |
| Лазер | `Пробел` | ЛАЗЕР |
| Карта и автопилот | `M`, нажать на планету | кнопка карты |
| Следующая цель / автопилот | `T` / `F` | ЦЕЛЬ / кнопка автопилота |
| Пауза и атлас | `P` | кнопка паузы |
| Звук | `N` | кнопка звука |

У планет корабль сам притормаживает, чтобы не пролететь насквозь. Автопилот облетает Солнце.

## Что есть в космосе

- **Солнце и 8 планет**, у Сатурна и Урана кольца, у Юпитера Большое красное пятно, у Земли облака и огни городов на ночной стороне.
- **16 лун**: Луна, Фобос, Деймос, Ио, Европа, Ганимед, Каллисто, Титан, Энцелад, Титания, Тритон, Харон и другие.
- **Карликовые планеты и малые тела**: Церера, Веста, Плутон, Хаумеа (вытянутая), Макемаке, Эрида, Седна, комета Галлея с хвостом, пояс астероидов и пояс Койпера.
- **Неизвестные миры** на краю системы: гипотетическая Девятая планета и четыре придуманных для игры — Кристалла, Пирос, Аквария и планета-бродяга Сумрак. На карте они видны как «? сигнал», пока не долетишь.

Подлетаешь к телу — появляется карточка с настоящими фактами. Всё посещённое попадает в атлас (в паузе), он хранится в браузере.

## Лазер

Лазер перегревается, если стрелять без перерыва. Им можно:

- сбивать астероиды (их много в поясах) — очки за каждый;
- сбивать чужие дроны — они появляются в космосе и стреляют зелёной плазмой по щиту;
- **уничтожить любую планету или луну**: у каждой есть запас прочности, поверхность трескается и светится, а потом планета взрывается облаком обломков. Солнце лазер не берёт.

В паузе есть кнопка «Восстановить Солнечную систему».

## Масштаб

1 единица ≈ 200 км, радиус Земли 32 единицы. Расстояния между планетами сильно сжаты, чтобы до Плутона можно было долететь за минуту на турбо, но порядок планет и их размеры относительно друг друга сохранены.

Публикуется вместе со школьным порталом на GitHub Pages по адресу `/star-voyage/`.

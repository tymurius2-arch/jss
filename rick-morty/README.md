# Рик и Морти: Портальный побег

Фанатская аркада-стрелялка по мультсериалу «Рик и Морти». Рик и Морти летят на космической тарелке через измерения: сбивают громфломитов, кроненбергов и метеориты, собирают мега-семена и прыгают в портал.

- `index.html` — вся игра в одном файле (без сборки, открывается прямо из файла). Персонажи нарисованы кодом на canvas, звуки (включая отрыжку Рика) синтезируются через Web Audio.

## Как играть

- Корабль водится пальцем (тянешь в любом месте экрана), мышью или стрелками / WASD. Стрельба автоматическая.
- Собери нужное число мега-семян — откроется портал. Влети в него, чтобы попасть в следующее измерение.
- Каждое третье измерение — босс «Голова в небе» («Покажи мне, что у тебя есть!»).
- С прыжками по измерениям пушка улучшается: с одного лазера до пяти.
- `P` / `Esc` — пауза, `M` — звук.

## Бонусы

| Бонус | Что делает |
|---|---|
| Мега-семя | Очки и заполнение шкалы портала |
| Огурчик Рик | 7 секунд неуязвимости: Рик превращается в огурец и таранит врагов |
| Коробка Мисиксов | Два мистера Мисикса 10 секунд стреляют рядом с кораблём |
| Сычуаньский соус | +1 жизнь (максимум 5) |

## Измерения

Земля C-137 → Мир Кроненбергов → Пространство Головы (босс) → Цитадель Риков → Газорпазорп → Аркада «Блипс и Читц» (босс), дальше по кругу и сложнее.

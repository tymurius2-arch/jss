# AutoBot

Press the **Bot** button next to Play on a level page (or **Bot: off** in the pause menu) and the bot plays the level for you:

1. It learns the level by trial and error: after each death it tries a new input a bit before the place it died. Every try starts from the beginning in normal mode (or from practice checkpoints, if you turn that on).
2. When it reaches the end, the route is saved.
3. Next time the level is passed right away.

Classic levels only (no platformer or 2-player). Safe mode (on by default) keeps bot runs from saving progress, stars or leaderboard results.

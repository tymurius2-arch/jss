# Запуск PODIL DRAGONS на своём домене

## 1. Что заполнить

Почти всё заполняется в одном файле, **`config.js`**. Пустое поле `""` значит, что этот блок на сайте не показывается.

| Поле | Что вписать | Пример |
|---|---|---|
| `domain` | Домен без `https://` | `podildragons.com.ua` |
| `phoneDisplay` | Телефон так, как его видно на сайте | `+380 67 123 45 67` |
| `phone` | Тот же телефон, только цифры и `+` (для звонка в один клик) | `+380671234567` |
| `email` | Почта, куда приходят заявки | `info@podildragons.com.ua` |
| `address` | Адрес офиса на укр. и англ. | `Київ, вул. ..., 10` |
| `hours` | Часы работы на укр. и англ. | `Пн–Пт, 10:00–19:00` |
| `mapQuery` | Адрес для карты Google | `Київ, вул. Сагайдачного, 10` |
| `social` | Ссылки на Telegram, Viber, WhatsApp, Instagram, Facebook | `https://t.me/podildragons` |
| `company` | ФОП или ТОВ и код ЄДРПОУ/ІПН (для подвала и политики конфиденциальности) | `ФОП Вихарєв М. ...` |
| `web3formsKey` | Ключ для отправки заявок на почту (см. ниже) | `a1b2c3...` |
| `portrait` | Фото архитектора | `img/portrait.jpg` |
| `projects` | Проекты для страницы «Про нас»: название, описание, фото | Хрещатик Плаза |
| `showExamples` | `false`, когда добавите настоящие объекты | |

### Объекты на продажу: `listings.js`

Сейчас там 6 примеров с пометкой «Приклад». В начале файла есть образец: скопируйте его, впишите настоящие данные и удалите примеры. Фото кладите в папку `photos/`.

### Заявки на почту: Web3Forms (бесплатно)

1. Откройте https://web3forms.com, введите почту из поля `email` и нажмите «Create Access Key».
2. Ключ придёт на почту. Вставьте его в `web3formsKey`.

Без ключа формы тоже работают, но тогда у посетителя открывается его почтовая программа, и часть людей не доведёт отправку до конца.

## 2. Домен

Купить можно у любого украинского регистратора: imena.ua, nic.ua, hostinger.com.ua. Зону `.com.ua` сейчас может зарегистрировать кто угодно. Для `.ua` нужна торговая марка.

Название домена впишите в `config.js`, а также замените `podil-dragons.example` в `index.html` (4 места), `robots.txt` и `sitemap.xml`.

## 3. Хостинг: Netlify (бесплатно, сам обновляется при каждом изменении в GitHub)

1. Зарегистрируйтесь на https://app.netlify.com через свой аккаунт GitHub.
2. Нажмите «Add new site» → «Import an existing project» → GitHub → репозиторий `jss`.
3. Настройки сборки:
   - Branch: `main`
   - Base directory: `podil-dragons`
   - Build command: оставить пустым
   - Publish directory: `podil-dragons`
4. Нажмите «Deploy». Сайт появится на адресе вида `что-то.netlify.app`.
5. Откройте «Domain management» → «Add a domain» и впишите свой домен.
6. В кабинете регистратора домена добавьте DNS-записи:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | `@` (сам домен) | `75.2.60.5` |
   | CNAME | `www` | `что-то.netlify.app` |

7. Через 10–60 минут сайт откроется на вашем домене. HTTPS Netlify включит сам.

## 4. После запуска

- Добавьте сайт в Google Search Console (https://search.google.com/search-console) и отправьте `sitemap.xml`.
- Создайте профиль в Google Business Profile с тем же адресом и телефоном, чтобы студию находили на карте.
- Отправьте ссылку на сайт себе в Telegram и проверьте, что показывается картинка с драконом.

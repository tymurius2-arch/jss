# PODIL DRAGONS

Сайт нерухомості та реконструкції в Києві для архітектора Миколи Вихарєва. Червоно-білий китайський стиль із великим анімованим драконом.

- `index.html` — розмітка всіх сторінок.
- `styles.css` — оформлення, світла і темна теми, анімації.
- `dragon.js` — дракон: малюється кодом у SVG і плавно рухається.
- `config.js` — **контакти, домен, соцмережі, реквізити, проєкти: усе, що треба заповнити**.
- `listings.js` — об'єкти на продаж (зараз — приклади).
- `i18n.js` — усі тексти українською та англійською, райони Києва.
- `app.js` — сторінки, оголошення, фільтри, форми, налаштування.
- `img/` — іконки та картинка для превʼю посилання; `photos/` — фото об'єктів.

**Як запустити на своєму домені — див. [DEPLOY.md](DEPLOY.md).**

## Сторінки

Головна · Продаж · Реконструкція · Про нас · Контакти · Налаштування.

У налаштуваннях: мова (UA/EN), валюта ($ / ₴ / €) з курсом, тема (світла / темна / як у системі), анімації, показ прикладів.

## Заявки

Форми «Виставити об'єкт» і «Написати нам» надсилають заявку на пошту з `config.js` (через Web3Forms, якщо вказано ключ, інакше — через поштову програму відвідувача). Об'єкт з'являється на сайті після того, як його додадуть у `listings.js`.

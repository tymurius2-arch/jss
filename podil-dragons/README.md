# PODIL DRAGONS

Сайт нерухомості та реконструкції в Києві для архітектора Миколи Вихарєва. Червоно-білий китайський стиль із великим анімованим драконом.

- `index.html` — розмітка всіх сторінок.
- `styles.css` — оформлення, світла і темна теми, анімації.
- `dragon.js` — дракон: малюється кодом у SVG і плавно рухається.
- `i18n.js` — усі тексти українською та англійською, райони Києва, приклади оголошень.
- `app.js` — сторінки, оголошення, фільтри, форма, налаштування. Контакти студії — в `CONFIG` на початку файлу.

## Сторінки

Головна · Продаж · Реконструкція · Про нас · Контакти · Налаштування.

У налаштуваннях: мова (UA/EN), валюта ($ / ₴ / €) з курсом, тема (світла / темна / як у системі), анімації, показ прикладів.

## Що треба зробити перед запуском

1. Вписати справжній телефон і пошту в `CONFIG` у `app.js`.
2. Замінити приклади оголошень у `i18n.js` (`PD_DEMO`) на справжні або вимкнути їх.
3. Оголошення, які додають через форму, зберігаються лише в браузері того, хто їх додав. Щоб їх бачили всі відвідувачі, потрібна база даних (наприклад, Firebase, як у `school-portal`).

Збирати нічого не треба — достатньо відкрити `index.html` через будь-який статичний сервер.
